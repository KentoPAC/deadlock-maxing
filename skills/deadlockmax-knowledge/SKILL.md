# Deadlock game knowledge (DeadlockMax)

`R` = `deadlockmax/skills/deadlockmax-knowledge/ref`, generated by
`python3 -I deadlockmax/scripts/knowledge.py R` from deadlock-api (official FR + EN data).

## 1. Check it is current (every time, it is fast)

`python3 -I deadlockmax/scripts/knowledge.py R --check`
If it says a patch came out, regenerate (same command without `--check`, ~10 s) before answering:
items and kits change with patches, never answer from an old reference or from memory.

## 2. Find the answer without reading everything

The files are large (index ~40 KB, items ~65 KB, heroes ~70 KB): search them, do not read them whole.

- **"Which item does X?"** -> `R/index.md`: one `## <effect>` section per effect, one line per item
  (French name (English name) — slot, tier, price, active — short effect). Sections: Anti-soin, Dégâts en % des PV,
  Réduit la résistance aux balles / à l'esprit adverse, Résistance aux balles / à l'esprit / aux effets, Réduit la
  cadence de tir / la puissance spirituelle / les dégâts adverses, Étourdit, Silence, Ralentit, Soulève, Barrière,
  Vol de vie, Soigne les alliés, Augmente les soins, Mobilité, Invisibilité, Recharge, Farm, Renvoie les dégâts,
  Évite la mort, Purge, Désarme.
  `grep -n -A12 "^## Anti-soin" R/index.md`
- **Details of an item** (full description, stats): `grep -n -A8 "^### Brise-tête\|(Crippling Headshot)" R/items.md`
- **A hero's kit**: `grep -n -A22 "^## Paradox" R/heroes.md` (type, tags, role, the 4 abilities with cooldowns).
- **Structured data** (scripts): `R/items.json` (`items`: id, fr, en, slot, tier, cost, active, tags, desc_fr,
  desc_en, stats; `heroes`: id, fr, en, abilities).

## 3. How to answer

- Name every item and ability with its **full official name**, French first then English in parentheses when the
  user may play in English ("Brise-tête (Crippling Headshot)").
- Give the price and tier: a 1600-soul item and a 6400-soul item are not the same answer.
- Tags come from the items' technical properties (and a few description keywords). Before stating an effect, check
  the item's description in `items.md`: a tag says the item has the effect, not how strong it is.
- When the question is "what should I buy against <hero>", the item list is not enough: say **when** it is worth it
  (timing, situation). Measured answers (who heals a lot and from when, what the item changes at equal game
  state) come from the DeadlockMax statistics; if they are not available, say what is measured and what is not.
- Never invent numbers: quote the stats line of `items.md`, or say they are not in the data.
